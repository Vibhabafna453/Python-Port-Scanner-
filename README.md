# Python Port Scanner

A simple TCP Port Scanner built using Python and the socket module.

#Features
- Scan common TCP ports
- Supports IP addresses and hostnames
- Displays OPEN and CLOSED ports
- Uses TCP socket programming

# Technologies
- Python
- Socket Programming
- TCP/IP Networking

# Ports Scanned
- 22 (SSH)
- 23 (Telnet)
- 25 (SMTP)
- 53 (DNS)
- 55
- 80 (HTTP)
- 110 (POP3)
- 443 (HTTPS)
```
#Example
Enter IP Address or Hostname:
google.com

Scanning google.com
------------------------------
Port 80 : OPEN
Port 443 : OPEN
------------------------------
Scanning completed!
```
